DataFluss 0.2.0

  • New: lessons and grades. Teachers see their lessons and classes and enter report grades, the grade book, conduct, days absent and learning progress, even without a connection.
  • A teacher's computer holds only their lessons and classes; of the pupils only name, class, photo and what matters for grades, no addresses and no parents.
  • The server only accepts changes the teacher would also be allowed to make in the browser. Grades entered offline before the end of the entry period still count up to two weeks later.
  • Reports, conference, checklist and grade lists can also be printed in DataFluss.
  • This version goes with the new server version with lessons and grades. Update the server first, then DataFluss on Mac and Windows; until then syncing pauses.

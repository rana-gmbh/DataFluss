DataFluss 0.2.2

  • On a Mac connected to the server, only the account the database was connected with can sign in. If you try another account, the sign-in page now names that account and the way to your own database via “Connect to server”, instead of reporting “wrong password”.
  • A password reset on the server no longer locks the Mac on the page “This only works in the web version”. The new password is set in the browser.

DataFluss 1.2.1

  • Connected databases open right after an update of the app. If the app lacked the module a database uses (such as the premium module), it now fetches the module from the server and opens the database straight away. Before, it reported the module as missing, and the database had to be connected again.
  • If the module cannot be fetched, the message now says why.
  • Update the server to 1.2.1 first: the app fetches the module of the server's version.

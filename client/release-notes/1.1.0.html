DataFluss 1.1.0

  • Regular backups on the computer: a database of your own backs itself up daily or weekly to a folder of your choice, such as another drive or a cloud folder. Set it up under Administration → Backup. The start page shows when a backup is missing or overdue.
  • Move to a server: a database started on the computer becomes the data of a DataFluss server, with all accounts, images and documents. The computer then connects to the server anew.
  • Full backup from the server: in a connected database, IT can download the server's full backup to the computer.
  • The server also needs DataFluss 1.1 for the move.

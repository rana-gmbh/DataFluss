DataFluss 1.1.0

  • Regelmäßige Sicherung auf dem Computer: Eine eigene Datenbank sichert sich täglich oder wöchentlich in einen Ordner Ihrer Wahl, etwa auf ein anderes Laufwerk oder in einen Cloud-Ordner. Einzurichten unter Verwaltung → Sicherung. Die Startseite zeigt, wenn eine Sicherung fehlt oder überfällig ist.
  • Auf einen Server übertragen: Eine Datenbank, die auf dem Computer begonnen hat, wird mit allen Konten, Bildern und Dokumenten zu den Daten eines DataFluss-Servers. Danach verbindet sich der Computer neu mit dem Server.
  • Vollständige Sicherung vom Server: In einer verbundenen Datenbank kann IT die vollständige Sicherung des Servers auf den Computer laden.
  • Für die Übertragung braucht der Server ebenfalls DataFluss 1.1.

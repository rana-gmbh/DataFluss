DataFluss 1.0.0

  • DataFluss ist jetzt Open Source (AGPL-3.0): github.com/rana-gmbh/DataFluss.
  • Die App enthält die Plattform und das Modul Schulverwaltung. Weitere Module kommen als signierte Dateien dazu: von dem Server, mit dem eine Datenbank verbunden ist, oder über „Modul installieren …“ auf der Startseite.
  • Verbundene Datenbanken, die ein solches Modul nutzen, öffnen sich wie bisher; das Modul hat der Computer schon vom Server geholt.

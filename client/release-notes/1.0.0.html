DataFluss 1.0.0

  • DataFluss is now open source (AGPL-3.0): github.com/rana-gmbh/DataFluss.
  • The app contains the platform and the module Schulverwaltung. Further modules come as signed files: from the server a database is connected to, or via “Install module …” on the start screen.
  • Connected databases that use such a module open as before; the computer has already fetched the module from the server.

DataFluss 0.5.0

  • Neue Datenbank mit Assistent: Ausgangspunkt wählen (Schulverwaltung), die Module dieser Installation dazunehmen oder weglassen, auf Wunsch mit Beispieldaten.
  • Erste Schritte: beim ersten Start eine kurze Einführung, beim ersten Anmelden ein Rundgang durch die Datenbank, auf der Startseite eine Liste, die sich selbst abhakt. Einführung und Rundgang gibt es jederzeit wieder im Menü Hilfe.
  • Module: Unterricht, DaZ und Kindergarten sind jetzt ein eigenes Modul. Eine Datenbank kann es nutzen oder weglassen. Verbundene Computer halten das Modul zusätzlich als signierte Datei vor, die der Server ausgibt.
  • Datum und Uhrzeit folgen der Zeitzone dieses Computers.
  • Unterschiedliche Versionen von Computer und Server werden beim Verbinden und Abgleichen mit beiden Versionsnummern genannt. Wurde der Server aus einer Sicherung wiederhergestellt, hält der Abgleich an, statt Änderungen zu übergehen.
  • Die Version steht unter Einstellungen.

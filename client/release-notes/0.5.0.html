DataFluss 0.5.0

  • New database with a wizard: choose a starting point (Schulverwaltung), add or leave out the modules of this installation, with sample data if you like.
  • First steps: a short introduction at the first start, a tour of the database at the first sign-in, and a checklist on the start page that ticks itself off. Introduction and tour are always available again in the Help menu.
  • Modules: Lessons, DaZ and Kindergarten are now a module of their own. A database can use it or leave it out. Connected computers also keep the module as a signed file that the server hands out.
  • Date and time follow this computer's time zone.
  • Different versions of computer and server are named with both version numbers when connecting and syncing. If the server was restored from a backup, syncing stops instead of skipping changes.
  • The version is shown under Settings.

# Security

DataFluss holds personal data, so security reports are welcome and taken seriously.

**Please do not open a public issue for a vulnerability.** Report it privately through GitHub:
**Security → Report a vulnerability** in this repository. We answer within a few working days, keep you
informed, and credit you when the fix is out, if you wish.

Supported: the latest release of the apps and the server image. Updates are signed and install
themselves, so a fix reaches everyone with the next release.
